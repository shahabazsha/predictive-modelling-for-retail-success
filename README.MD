# Student Management System

A beginner-friendly Student Management System built with Python.

## Features

- Add students
- View all students
- Search for a student
- Update student information
- Delete students
- Save student data to a text file
- Read data from the text file
- Handle invalid input using try/except

## Technologies Used

- Python
- File Handling
- Lists
- Dictionaries
- Functions
- Loops
- If/Else
- Exception Handling
